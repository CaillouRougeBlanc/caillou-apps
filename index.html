Caillou Apps — iPhone

Cette édition adapte les applications du programme ordinateur à l’écran tactile. Les interfaces qui utilisaient Tkinter/Pygame ont été réécrites pour fonctionner dans Safari.

Les sauvegardes compatibles utilisent le stockage local de l’iPhone. Certaines fonctions qui dépendent d’Internet ouvrent un service externe.
